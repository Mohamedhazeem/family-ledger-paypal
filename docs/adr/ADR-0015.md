# ADR-0015: Configuration & secrets: env vars only, .env.example, no secrets in code or logs
- Status: Accepted
- Date: 2026-11-06
- Deciders: Tech Lead, Founding Engineering
- Spec refs: Part C §13, Part F §24 (env list), Part H #8–9
- Supersedes: none

## Context
PayPal, AI, DB, encryption keys must never land in tracked files or logs.
## Decision
All secrets via environment variables; tracked `.env.example` with variable names only (plus placeholders); required list per §24.
## Consequences
### Positive
- Secure defaults, Render integration, auditable.
### Negative / trade-offs
- Local setup friction.
### Risks & mitigations
- Leak via logs/commits — redaction, .gitignore for `.env*`.
## Alternatives considered
Config files — rejected.
## Implementation guardrails
- MUST NOT commit `.env`; MUST name vars only, never ask user to paste secrets into code/chat.
## Verification
- Git check: no real secrets tracked; grep for secrets in logs tests.
