# ADR-0005: AI behind a provider-agnostic port; structured JSON + Zod; AI is advisory-only and cannot mutate payment state
- Status: Accepted
- Date: 2026-11-06
- Deciders: Tech Lead, Founding Engineering
- Spec refs: Part A §4 #8–9, Part C §12, Part B §Steps 2, 6
- Supersedes: none

## Context
AI must parse intent, explain diffs, translate — without determining eligibility or triggering payout.
## Decision
`AiProvider` port (`src/services/ai/provider.ts`) with OpenAI + Mock adapters. Structured output validated by Zod (`services/ai/schemas.ts`); evidence required; diff computed deterministically; fallback templates.
## Consequences
### Positive
- Swappable provider via env; no AI control of money; safe explanations tested.
### Negative / trade-offs
- Prompt/schema overhead; AI unavailable fallback needed.
### Risks & mitigations
- Invented amounts — deterministic validation, block publish on over-total, show remainder only after confirmation.
## Alternatives considered
Direct OpenAI calls in handlers — rejected: lock-in, untestable.
## Implementation guardrails
- MUST NOT let AI change payout amount/recipient/status; MUST treat notes as untrusted; MUST NOT log sensitive free text.
## Verification
- Integration tests: Zod rejects malformed output; diff tests independent of AI; unavailable-AI fallback tested.
