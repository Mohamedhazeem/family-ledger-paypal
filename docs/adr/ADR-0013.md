# ADR-0013: File-size policy (300 LOC) + module decomposition strategy
- Status: Accepted
- Date: 2026-11-06
- Deciders: Tech Lead, Founding Engineering
- Spec refs: Engineering policy (labels in AGENTS §12); Part C §8 structure
- Supersedes: none

## Context
God-files cause unmaintainability and merge conflicts in a six-day build.
## Decision
Hard limit: no source file >300 LOC. Enforce via lint/check script. Splitting playbook: extract services, hooks, schemas, mappers, components.
## Consequences
### Positive
- Cohesive modules, reviewable PRs, better testability.
### Negative / trade-offs
- More files/indirection; premature splits possible.
### Risks & mitigations
- Over-splitting — split by responsibility, not line-chasing.
## Alternatives considered
No limit — rejected.
## Implementation guardrails
- MUST run file-size check in CI/pre-commit; MUST document any exception via ADR.
## Verification
- CI fails on >300 LOC file.
