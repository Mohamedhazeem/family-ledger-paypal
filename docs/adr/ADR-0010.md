# ADR-0010: Sponsor analytics: AG Studio over aggregate-only views + Studio Agent Framework; explicit fallback to AG Grid and its trade-offs
- Status: Accepted
- Date: 2026-11-06
- Deciders: Tech Lead, Founding Engineering
- Spec refs: Part C §7 (AG Studio), Part D §14G, Part G (risk: AG Studio access)
- Supersedes: none

## Context
Primary sponsor prize needs real AG Studio analytics, not a plain grid. Access/packages may be blocked.
## Decision
AG Studio embedded analytics over restricted aggregate views + Studio Agent Framework (aggregate-only tools). Fallback: AG Grid React register if access blocked.
## Consequences
### Positive
- Sponsor-aligned dashboards + agent answers; data minimization.
### Negative / trade-offs
- Licensing/setup risk; fallback weakens sponsor case (record honestly).
### Risks & mitigations
- Core workflow first; verify access Day 0; agent must never see emails/token hashes/notes/explanations, never mutate.
## Alternatives considered
Plain grid only — rejected as sponsor claim.
## Implementation guardrails
- MUST query aggregate-only view for agent; MUST NOT expose recipient emails/private notes to analytics agent.
## Verification
- Analytics tests: aggregate queries correct; agent questions answered; fallback path tested.
