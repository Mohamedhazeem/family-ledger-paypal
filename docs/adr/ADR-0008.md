# ADR-0008: Field-level encryption for PayPal recipient email (AES-256-GCM, app-layer) with dedicated APP_ENCRYPTION_KEY
- Status: Accepted
- Date: 2026-11-06
- Deciders: Tech Lead, Founding Engineering
- Spec refs: Part C §9 (`encryptedPayPalRecipient`), §13
- Supersedes: none

## Context
PayPal recipient email is sensitive, server-only; DB compromise should not expose it.
## Decision
AES-256-GCM app-layer encryption at rest with dedicated `APP_ENCRYPTION_KEY` env var.
## Consequences
### Positive
- Defense in depth; clear key rotation surface.
### Negative / trade-offs
- Key management burden.
### Risks & mitigations
- Key loss = data loss — document storage in Render env; encrypt+decrypt only server-side.
## Alternatives considered
Plaintext columns — rejected: violates spec/security. KMS-only — deferred for MVP simplicity.
## Implementation guardrails
- MUST NEVER return decrypted email to beneficiary portal or register grid.
## Verification
- Unit tests: encrypt/decrypt round-trip, tamper detection, redaction in logs.
